# Vector AI Launchpad

The first version of the Vector AI launch site: services, pricing and a how-it-works flow for an AI services studio. The later build is in [vector-ai](https://github.com/heetsanghvvii/vector-ai).

**Pages:** home, pricing, and one page each for content, research, creative, business operations, data analysis, and chatbots and automation.

## Stack

TanStack Start, React, TypeScript, Vite, Tailwind, deployable on Cloudflare Workers.

## Run it

```bash
bun install
bun run dev
```
